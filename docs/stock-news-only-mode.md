# 株式ニュース専用モード

この変更では、アプリの通常導線を「登録した銘柄のニュースを取得し、日次レポートとして保存・閲覧する」用途に限定します。

## 通常画面に残す機能

- 銘柄の追加・停止・削除
- 銘柄ごとの取得時刻、頻度、言語、記事数などの設定
- 今日のニュース
- 銘柄別の日次レポート
- 横断検索、お気に入り、既読管理
- 実行履歴、通知履歴
- 保存済みレポートへのAI質問
- ニュースレポートPDFの閲覧
- 旧PDFアーカイブの読み取り専用閲覧
- クラウド連携、通知、外観設定

## 通常画面から外す機能

- PDFの手動追加
- 画像からPDF作成
- カメラスキャン
- PDFの結合・分割・ページ編集
- PDFの名前変更・移動・コピー
- タグ、メモ、重要度の手動設定
- 自動分類ルール
- 学習レポートPDFの自動取込
- Geminiによる汎用PDF作成
- 旧PDF向けのバックアップ・復元・表示設定

旧PDFはデータ消失を避けるため削除せず、「旧PDFアーカイブ」から閲覧だけできる状態にします。

## 実装方法

`src/app/page.tsx` では旧 `AppShell` を使用せず、株式ニュース専用の `StockNewsAppShell` を起動します。これにより、旧機能のコンポーネントやバックグラウンド取込処理は通常起動時に読み込まれません。

旧コードの物理削除は、保存済みデータの移行と互換性を確認した後の第2段階で行います。第1段階では、利用者のデータを保持しながら旧機能を確実に無効化することを優先します。
